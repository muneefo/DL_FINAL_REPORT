\section{Independent Evaluation and Completion Experiments}

The legacy results above are retained for reproduction. The following evaluation calibrates a null threshold, selects a beam using validation observations, and freezes both before testing on separate observations. Each frame draws its own target range, correcting the legacy shared-range batches. No independently sorted interpolation is used.

Null calibration, validation and test use 10,000, 10,000 and 20,000 frames, respectively, with distinct seeds. The validation SER constraint is 1\%; a test violation is reported rather than used to reselect a beam. Wilson intervals quantify test-frame detection uncertainty for fixed models, separately from hardware/optimization variability.

The sweep uses fresh online training scenes; supervised observation counts equal supervised updates times batch size, and are not unique fixed-pool acquisition labels. Two optimization seeds do not establish statistical equivalence.

SNR evaluation changes test sensing SNR to 5, 10, 20 and 25 dB without retraining. Independent localization uses new scene seed 93001 and noise seed 94001, saves per-scene errors, and decomposes squared position error exactly into radial and angular contributions.
